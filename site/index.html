tend

From the ticket to the pull request, with agents.

A terminal built for AI coding agents. tend takes a GitHub issue or a production error, opens a worktree and hands it to Claude Code, Codex or whichever agent you use — and shows you every one of them on one screen: working, waiting for you, or done.

Install Star on GitHub stars

tend is open source. Your star helps more people discover the project.

Linux and macOS · Windows through WSL · one binary, open source

The programs
A session is a background server. ctrlb then d leaves the agents running. Opening tend again attaches to the same panes.
The state
A pane is working, blocked, or idle. The mark is what the screen is showing — a spinner, a permission prompt, a shell waiting — not a guess about the process name.
The layout
A space holds tabs. A tab holds panes. Split beside or below, zoom one pane, scroll its history, jump to the agent that stopped.

Install 

curl -fsSL https://tend.auth.com.br/install.sh | sh

Download tend-linux-amd64 · arm64 · all builds

Puts a binary in ~/.local/bin (or $GOBIN / $TEND_INSTALL_DIR). Prefers a release build for this machine; otherwise clones and builds with Go.

From a checkout: make install.

tend is Linux and macOS only. There is no Windows binary.

On Windows, run the Linux installer inside WSL, or clone and make install on a Unix machine. The WSL guide walks through it.

tend — work

A real session: one agent working, one waiting for you to approve a command, a third asleep, and the project's files beside them. The server is still there when nobody is looking.

With no arguments, tend opens a session and starts a server if there is not one. tend new -- claude opens a pane. tend ls lists what is running. -s NAME runs another session beside the first.

Written in Go. One binary. No cgo.

Tools, over the spaces

Buttons at the top of the sidebar, each with a key after the prefix.

Files f

A panel beside your panes: the project's tree, a search through it, and its git changes — diff, stage, commit, push. It follows the pane you are working in.

Agents A

The agent CLIs tend knows — Claude Code, Codex, Gemini CLI, Cursor, OpenCode and more — which this machine has, and the install command for the rest, run in a tab once you say yes.

Sleeping agents

After a restart an agent starts only when you go to its pane, in the conversation it was in. One left idle gives its memory back by itself, so twenty agents across projects do not weigh on the machine.

MCP servers M

Every agent's MCP servers in one grid: switch one on or off in any agent, test it, copy it to another agent, add one from a single line.

Permissions P

What each agent may do without asking, for your machine and for the project: change a rule between allow, ask and deny, or open the file in your editor.

Companies O

Working for several companies? Keep each one's spaces together and choose one: the sidebar shows that company's projects and agents, and an agent waiting in another is still flagged.

GitHub · GitLab I

The project's issues and pull requests, through gh. Comment, close, label, merge. w on an issue makes a worktree for it and starts your agent there, told to complete it. Projects on GitLab — gitlab.com or your company's — work the same, with their merge requests.

Sessions S

Every Claude Code conversation on the machine, by its title. Type to search, enter to resume one in a new tab where it was held, mark old ones and delete them.

Errors E T

What your systems' GlitchTip servers caught, as many servers as you report to. Open an error to read its stack; f hands it to your agent, w fixes it in a worktree, ctrlx resolves it. Each project can open on its own server. Tickets from Linear, Jira and ClickUp are in a panel of their own, T, with the same way to hand one to your agent.

Browser and context B C

A Chromium, Chrome or Edge window with tend's extension: pick elements on a page, note what you want of each, and send them to the agent, looked over first in the context panel.

Your phone

tend web serves a page for your phone, on your home network or your VPN: every agent with what it is doing, its screen live, a box to message it, and a buzz when one needs you. Agents only — never a shell.

Updates

tend notices a new release and says so. u in its notes installs it and moves the running session onto it, without stopping the programs in its panes.

On your phone

Away from the desk, the agents keep working — and you keep following them. tend web serves a page for your phone: no app to install, nothing leaves your network.

tend web

Run it on the computer and open the address it prints on the phone — once, to pair it — or set a login and password with tend web -set-password. The phone buzzes when an agent needs you or finishes. Add it to the home screen and it opens like an app.

It reaches agents only, with a fixed list of actions: a message, the keys an agent asks for, wake and sleep. Never a shell. On your home network, or anywhere through your VPN.
