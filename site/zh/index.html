tend

从工单和生产错误到 pull request，交给智能体，不离开终端。tend 接收一个 GitHub issue 或 GlitchTip 错误，创建 worktree，交给 Claude Code、Codex 或你使用的任何智能体。每个窗格标为 working、blocked 或 idle，已解决的在同一屏幕上关闭。

安装 

curl -fsSL https://tend.auth.com.br/install.sh | sh

下载 tend-linux-amd64 · arm64 · 全部构建

将二进制放到 ~/.local/bin（或 $GOBIN / $TEND_INSTALL_DIR）。优先使用适合此机器的发布包；否则用 Go 克隆并编译。

从源码目录：make install。

tend 仅支持 Linux 和 macOS。没有 Windows 二进制文件。

在 Windows 上，请在 WSL 中运行 Linux 安装命令，或在 Unix 机器上克隆后执行 make install。 步骤见 WSL 指南。

一次会话。没人看着的时候，服务器也还在。

不带参数时，tend 打开会话，若没有服务器则启动一个。tend new -- claude 打开窗格。tend ls 列出正在运行的。-s NAME 在旁边再开一个会话。

用 Go 写成。单一二进制。无 cgo。

断开后仍会留下的

程序
会话是后台服务器。ctrlb 再按 d 后智能体继续运行。再次打开 tend 会回到同样的窗格。
状态
窗格是 working、blocked 或 idle。标记来自屏幕上的内容 — 转圈、权限提示、等待中的 shell — 不是根据进程名猜测。
布局
space 容纳标签。标签容纳窗格。左右或上下分割，放大一个窗格，滚动历史，跳到停下来的智能体。

空间上方的工具

侧边栏顶部的按钮，每个都可在前缀后用一个键打开。

文件 f
窗格旁的面板：项目的文件树、在其中搜索，以及 git 改动 — diff、暂存、提交、推送。它跟随你正在工作的窗格。
代理 A
tend 认识的代理 CLI — Claude Code、Codex、Gemini CLI、Cursor、OpenCode 等 — 这台机器装了哪些，以及其余的安装命令，确认后在标签页中运行。
会话 S
本机所有 Claude Code 对话，按标题列出。输入即可搜索，回车在原目录的新标签页中恢复，标记旧会话并删除。
GitHub · GitLab I
通过 gh 查看项目的 issue 和 pull request。评论、关闭、打标签、合并。在 issue 上按 w 会为它创建 worktree，并在其中启动你的代理去完成它。 GitLab（gitlab.com 或公司自建的）上的项目同样可用，包括合并请求。
浏览器与上下文 B C
带 tend 扩展的 Chromium、Chrome 或 Edge 窗口：在页面上选取元素，为每个写下要求，先在上下文面板中查看，再发送给代理。
错误 E T
你的系统的 GlitchTip 服务器捕获的错误，支持多个服务器。打开错误查看堆栈；f 交给智能体，w 在 worktree 中修复，ctrlx 标记解决。每个项目可以打开自己的服务器。 Linear、Jira 和 ClickUp 的工单有自己的面板 T，同样可以交给智能体。
公司 O
同时为多家公司工作？把每家公司的 space 放在一起并选择一家：侧边栏只显示该公司的项目和智能体，其他公司里等待的智能体仍会提示。
更新
tend 会发现新版本并提示。在更新说明中按 u 即可安装，并在不停止窗格中程序的情况下把会话迁移过去。
