tend

Do ticket e do erro de produção até o pull request, com agentes, sem sair do terminal. O tend pega uma issue do GitHub ou um erro do GlitchTip, abre um worktree e entrega ao Claude Code, ao Codex ou ao agente que você usa. Você acompanha todos — cada painel marcado como working, blocked ou idle — e fecha o que foi resolvido, na mesma tela.

Instalar 

curl -fsSL https://tend.auth.com.br/install.sh | sh

Baixar tend-linux-amd64 · arm64 · todos os builds

Coloca o binário em ~/.local/bin (ou $GOBIN / $TEND_INSTALL_DIR). Prefere um release para esta máquina; senão clona e compila com Go.

A partir de um checkout: make install.

O tend é só Linux e macOS. Não há binário para Windows.

No Windows, rode o instalador Linux no WSL, ou clone e make install numa máquina Unix. O guia do WSL mostra o caminho.

work · tend · agents1:claude ●2:codex ▲

Uma sessão. O servidor continua quando ninguém está olhando.

Sem argumentos, o tend abre uma sessão e sobe um servidor se ainda não houver. tend new -- claude abre um painel. tend ls lista o que está rodando. -s NAME roda outra sessão ao lado da primeira.

Escrito em Go. Um binário. Sem cgo.

O que fica quando você desconecta

Os programas
Uma sessão é um servidor em segundo plano. ctrlb e depois d deixa os agentes rodando. Abrir o tend de novo volta aos mesmos painéis.
O estado
Um painel está working, blocked ou idle. A marca é o que a tela mostra — um spinner, um pedido de permissão, um shell à espera — não um chute pelo nome do processo.
O layout
Um space guarda abas. Uma aba guarda painéis. Divida ao lado ou abaixo, amplie um painel, role o histórico, salte para o agente que parou.

Ferramentas, acima dos spaces

Botões no topo da barra lateral, cada um com uma tecla depois do prefixo.

Arquivos f
Um painel ao lado dos seus: a árvore do projeto, uma busca nela e as mudanças do git — diff, stage, commit, push. Ele segue o painel em que você está trabalhando.
Agentes A
Os CLIs de agentes que o tend conhece — Claude Code, Codex, Gemini CLI, Cursor, OpenCode e outros —, quais esta máquina tem e o comando para instalar os outros, rodado numa aba quando você confirma.
Sessões S
Todas as conversas do Claude Code na máquina, pelo título. Digite para buscar, enter retoma uma numa aba nova onde ela aconteceu, marque as antigas e apague.
GitHub I
As issues e os pull requests do projeto, pelo gh. Comente, feche, ponha rótulos, faça merge. w numa issue cria um worktree para ela e abre seu agente lá, com a issue como tarefa.
Navegador e contexto B C
Uma janela do Chromium, Chrome ou Edge com a extensão do tend: escolha elementos numa página, anote o que quer de cada um e mande para o agente, revisando antes no painel de contexto.
Erros E
O que os servidores GlitchTip dos seus sistemas pegaram, quantos servidores você tiver. Abra um erro para ler a pilha; f entrega ao seu agente, w conserta num worktree, ctrlx resolve. Cada projeto pode abrir no seu próprio servidor.
Empresas O
Atende várias empresas? Guarde os spaces de cada uma juntos e escolha uma: a barra lateral mostra os projetos e agentes daquela empresa, e um agente esperando em outra continua sendo avisado.
Atualizações
O tend percebe um release novo e avisa. u nas notas instala e passa a sessão para a versão nova, sem parar os programas dos painéis.
